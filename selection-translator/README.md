# 划词翻译 · Copilot Luna

Windows 10/11 原生后台小工具：**划选文字 → 附近出现圆角「翻译」按钮 → 点击后才请求模型，就近显示译文。** 只划选不发送原文。使用系统自带的 Windows PowerShell 5.1、WPF 和 Windows Forms 托盘组件，无额外依赖。

## 启动与托盘

双击 `selection-translator/start.cmd`，或在仓库根目录运行：

```powershell
powershell.exe -NoProfile -STA -ExecutionPolicy Bypass -File .\selection-translator\start.ps1
```

- 系统托盘出现一个 **「译」图标**；Windows 可能把它折叠到任务栏的向上箭头里。
- 点击译文框右上角 **×**、按 **Esc**、Alt+F4 或最小化，只隐藏窗口；**划词功能仍在后台运行**，不会在任务栏占一个应用按钮。
- 双击托盘图标，或右键选择「显示译文」，恢复窗口。
- 托盘右键「暂停划词」/再次点击恢复，统一暂停/恢复鼠标选区与快捷键入口。
- **要彻底退出，请从托盘右键选择「退出」**。退出会移除图标、关闭小按钮、取消请求并释放鼠标监听和快捷键。
- 每个 Windows 会话只运行一个实例，不自动修改开机启动。需要时可把 `start.cmd` 的快捷方式放进 `shell:startup`。

## 使用与界面

1. 在浏览器、编辑器等应用中划选文字、松开鼠标；350ms 后在划选结束点附近出现小「翻译」按钮，支持双击选词。
2. **点击按钮才发送选中文字到 Copilot**。按钮不抢焦点，使用点击前捕获的选区。
3. **译文以真实流式方式显示**：模型一返回文字就追加到卡片，可边生成边阅读、复制当前内容，不等待全文完成。不会强行把阅读位置滚到末尾；布局适度限频，避免逐字调整导致抖动。
   译文卡片以白色为主：圆角、轻阴影、无原文区、无输入线框，只保留译文、复制和关闭。短译文自动收缩，长译文限制高度并滚动，可拖动标题区域移动。
4. 译文框在选区附近显示，靠近右侧/底部时向左/向上调整，限制在所在显示器工作区内，避开任务栏；定位支持负坐标和物理像素 DPI 换算。
5. 点击其他位置、切换前台应用或暂停时，小按钮消失，不触发请求。相同文字再次划选仍可显示按钮，必须再点击才重新翻译。
6. 外语 → 简体中文；中文 → 英文，每次最多 8000 个字符。「复制」按钮只复制译文，不包含原文或状态提示。
7. 窗口隐藏到托盘后仍可划词；点击小按钮才重新显示译文框。关闭正在翻译的窗口不会中止后台请求，也不会在完成时突然重新弹出。
8. Ctrl+Alt+T 是键盘选区的备用入口，同样只显示按钮，不直接发送原文。暂停划词时也暂停该入口。

Luna 的模型名称为 **GPT-5.6 Luna**（`gpt-5.6-luna`）。需要指定其他已获授权的 Responses API 模型或凭据位置时：

```powershell
.\selection-translator\start.ps1 -Model gpt-5.6-luna -AuthPath "$HOME\.pi\agent\auth.json"
```

## 登录与隐私

- 复用 `$HOME\.pi\agent\auth.json` 的 `github-copilot` 登录；缺少凭据时需先在 pi 中登录 GitHub Copilot。仅读取文件，刷新令牌仅在内存缓存，不改写原文件。
- 划选只在本机暂存选中文字，不换取令牌、不调用翻译模型；**点击翻译才联网**。密码控件不读取，请勿主动发送密钥、密码或机密资料。
- 只发送选中文字，不发送整篇文档；请求设为 `store: false`，不在本地保存原文日志或历史。云端数据处理仍以你的 Copilot 方案和组织策略为准。
- **不发送 Ctrl+C，不读取或改写剪贴板**。「复制」按钮是唯一主动写入剪贴板的操作。
- 请求可能消耗订阅配额，不自动重试失败请求；新翻译取消旧请求，避免旧译文覆盖新内容。
- 使用与仓库现有 Copilot 工具相同的 token exchange + Responses 接口；它不是 GitHub 承诺稳定的通用第三方桌面应用 API，可能随服务更新而失效。

## 限制与排查

- 没有窗口不等于没有运行：先检查系统托盘的「译」图标。升级时请先从托盘退出旧版，再双击启动。
- 选区读取依赖 UI Automation TextPattern；部分 PDF、终端、游戏、自绘控件无法读取。当前界面不提供原文输入框，也不做 OCR，不会覆盖剪贴板绕过限制。
- 普通权限下不保证读取管理员权限应用，不自动提权。
- 位置以鼠标划选结束点为锚点；键盘入口以当前鼠标位置为锚点。原生托盘图标和菜单会遵循 Windows 的显示/折叠规则。
- 通过 Responses API 的 SSE `response.output_text.delta` 直接显示文字，只在收到完成事件后标记完成；不把推理或完成快照重复追加到译文。
- 首段出现仍取决于模型首字延迟和网络；流式可以省去「必须等整段生成结束才能阅读」的等待，不保证立即出字，也不会用打字动画模拟流式。
- 模型权限、登录过期、限流或网络错误显示在译文框下方，不会悄悄换模型。**60 秒超时覆盖整个请求和流式读取**；连接中断时保留并明确标注「部分译文」，仍可复制，不自动重试。

## 验证

```powershell
# SSE 分包/UTF-8/取消、输入和定位；也跑受控 WPF 流式界面测试
# 不调用网络、不操作鼠标，可在锁屏状态运行；会短暂创建测试窗口
powershell.exe -NoProfile -STA -File .\selection-translator\start.ps1 -Test

# 真实关窗后台划词 → 圆角按钮 → 点击 → 模拟 Copilot → 极简译文
# 验证首段显示时服务仍被阻塞、托盘暂停/恢复/显示/退出
# 需要桌面解锁；会短暂移动鼠标、切换焦点并恢复
# 请先从托盘退出已运行的工具，避免全局快捷键占用
powershell.exe -NoProfile -STA -File .\selection-translator\start.ps1 -Smoke

# 直接验证后端，以流式方式打印译文（会发送测试文本，可能消耗配额）
powershell.exe -NoProfile -STA -File .\selection-translator\start.ps1 -Probe 'Hello, world!'
```

受控测试覆盖增量先于完整响应显示、分包 UTF-8、多行 SSE、EOF/失败/取消、部分译文标注、隐藏窗口不重弹、暂停中止流、新请求不被旧流覆盖。真实鼠标桌面测试还覆盖关闭隐藏、后台划词、只划选零请求、显式点击单次请求、结果唯一与复制可用、圆角外观、托盘菜单和资源清理、不抢焦点与剪贴板不变。测试将固定模拟内容的界面预览导出到系统临时目录 `selection-translator-result.png`、`selection-translator-button.png`，不包含用户内容。

多显示器边界有纯定位断言，实际硬件和应用兼容性仍需验证。
