# Copilot global instructions

- When Search-MCP tools are available and ready, use Search-MCP to fetch web content.
- For a known URL, prefer `Search-MCP-browse`.
- For general web lookup before fetching a page, prefer `Search-MCP-web` or `Search-MCP-classic`.
- Fall back to other web-fetching tools only when Search-MCP is unavailable or fails.
